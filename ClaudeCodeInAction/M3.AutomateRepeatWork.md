

# Routines and Headless
Routines run on Anthropics infrastructure, headless runs on locally using the Agent SDK.

## Routines

A routine bundles three things: a prompt, the repository it works on, and any connectors it needs. Then it runs that bundle on Anthropics infrastructure whenever it's triggered.

Routines can trigger
- As a cron
- Via HTTP post to API endpoint
- An event, like a new github pull request

Routines can be scheduled using the web portal or the /schedule skill.

## Headless

This runs on your own environment. 

Run from the command line using the -p flag.
```
claude -p "summarize the changes in this diff"
```
or 
```
claude -p "Find and fix the bug in auth.py" --allowedTools "Read,Edit,Bash"
```

You can get structured output back:
```
claude -p "Extract the exported function names from src/core/style.js" \
  --output-format json \
  --json-schema '{"type":"object","properties":{"functions":{"type":"array","items":{"type":"string"}}},"required":["functions"]}' \
  | jq '.structured_output.functions'
```
You can resume a session in headless:
```
claude --resume "$(jq -r .session_id /tmp/plan.json)"
```
The --bare flag triggers the agent to run similarly on any enviroment. It will not discover mcp servers, plugins, skills, subagents or custom commands. It still maintains --mcp-config, --plugin-dir/--plugin-url, and  --agents to add back these resources. 

> --bare is the recommended mode for scripted and SDK calls, and will become the default for -p in a future release.

## Agent SDK: Claude Code inside an app

The Agent SDK is a library that embeds Claude Code inside your own TypeScript or Python applications.

```
import asyncio
from claude_agent_sdk import query, ClaudeAgentOptions, AssistantMessage, ResultMessage

async def main():
    async for message in query(
        prompt="Review utils.py for bugs that would cause crashes. Fix any issues you find.",
        options=ClaudeAgentOptions(
            allowed_tools=["Read", "Edit", "Glob"],
            permission_mode="acceptEdits",
        ),
    ):
        if isinstance(message, ResultMessage):
            print(f"Done: {message.subtype}")

asyncio.run(main())
```

# GitHub Actions and Code Review

## Code Review

Anthropic-hosted service which reviews pull requests throuhg the Claude GitHub app.

Triggers:
- Once when a PR opens
- On every push to the PR
- Only when someone comments @claude review

Mind the cost - a single review could cost $25.

- Does not approve or block PR. Only raises flags.
- No managed autofix - findings only
- Research preview.

## Github Action

Custom CI.
Run agent
- on PR comment
- on schedule
- on any GitHub event

Setup inside Claude with /install-github-app.

## Workflow

Add workflow
```
.github/workflows/claude.yaml
```
listens for ```@claude``` on PR/issue comments.
```
- uses: anthropics/claude-code-action@v1
  with:
    anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
    github_token: ${{ secrets.GITHUB_TOKEN }}
    trigger_phrase: "@claude"
    prompt: "Your instructions here"
    claude_args: "--max-turns 5 --model claude-sonnet-5"
```
