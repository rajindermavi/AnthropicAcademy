
Steering Long Sessions gives guidance on maintaining an agent with focused instructions over long sessions.

## Commands:

- /compact
    - Use the command with instructions of the focus.
    - /compact Focus on [subset_of_agents_activity]
- /rewind
    - Rolls back conversation and file changes to previous checkpoint.
    - Options
        - Restore code and conversation
        - Restore conversation
        - Restore code
        - Summarize from here / up to here
- /loop
    - Functions like a local, short-term cron job automating repetitive monitoring or iteration.
    - /loop [interval] [prompt_or_skill]
- /goal
    - Initiates a Claude agent that works autonomously until specified goal is accomplished
    - The worker writes code which is submitted to the evaluator. Loop continues until the goal is accomplished.
    - /goal [your_condition] (Starts an autonomous session based on your prompt)
