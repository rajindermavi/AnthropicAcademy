
# Unsupervised Runs

When agent runs are unsupervised they should be verified after the fact inversely proportion to their supervision.

Check the diff.
- run ```/code-review``` to walk changes an flag issues.
- Check ```git diff``` by eye.
Understand what files are changed and why.

The gate on unsupervised runs is passages of tests. Ensure they pass on agent runs.
Set up hooks 
- **stop hook** refuse to end the run on a failure
- **post-tool-use hook** lint and type check after edits

Enact a code review agent after unsupervised runs, it has no memory of how the code was built so it will act as fresh eyes on the update.

# Plugins

Install with command
